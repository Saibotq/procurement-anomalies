# Кейс 3. Генерация продуктовых гипотез (VPN-сервис)

Анализ дампа БД и логов инцидентов подписочного VPN-сервиса: пять продуктовых гипотез с подтверждением данными.
Итоговый отчёт: `report_case3_product_hypotheses.pdf`.

## Требования

- Python 3.10+
- `pip install duckdb`

## Данные

Данные (CSV-дамп БД и `logs.zip`, около 5 ГБ) в репозиторий **не входят**: они большие и содержат персональные данные пользователей.
Для запуска положите файлы владельца сервиса в папку `data/` так, чтобы структура была такой:

```
data/
  *.csv                 # таблицы БД, user_connection_logs* и др.
  logs.zip              # вложенные архивы с клиентскими логами
  db_structure/         # описание столбцов таблиц
```

## Порядок запуска

Скрипты запускаются из папки проекта: `python <скрипт>.py`.

| Скрипт | Назначение |
|---|---|
| `load.py` | подключает CSV к DuckDB (`practice.duckdb`), имена столбцов берёт из `data/db_structure` |
| `explore.py` | первичный обзор данных |
| `h3.py` | гипотеза 3: путь от free до покупки |
| `h1.py`, `h1b.py`, `h1c.py` | гипотеза 1: повторные аккаунты ради триала |
| `logs1.py`, `logs2.py` | изучение структуры `logs.zip` на одном архиве |
| `logs3.py` | разбор всех архивов логов, создаёт `incidents.csv` (10–30 минут) |
| `h4.py`, `h4b.py` | гипотеза 4: паттерны ошибок и активность после инцидента |
| `h2.py`, `h2b.py` | гипотеза 2: лимиты free-тарифа (по рекламе и подключениям) |
| `h5.py` | гипотеза 5: реферальная программа |

`incidents.csv` — агрегированная таблица по 926 инцидентам (версия приложения, ОС, счётчики ошибок), персональных данных в ней нет.

## Гипотезы и результат

1. Повторные аккаунты ради триала: подтверждена частично (260–390 повторных триалов, 1–2 %).
2. Лимиты free-тарифа: подтверждена частично (в 78,5 % дней реклама не нужна); объёмы трафика в данных отсутствуют.
3. Путь до покупки: подтверждена (65 % покупок через триал, медиана 3 дня; 35 % без триала).
4. Паттерны ошибок: подтверждена (сетевые сбои, зависят от версии приложения).
5. Реферальная программа: подтверждена (конверсия приглашённых 21 % против 1 %).
